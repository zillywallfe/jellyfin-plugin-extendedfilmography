Extended Filmography

Adds an actor's best-known films and series from TMDb to their person page, including titles you do not have. Nothing is written to the library database, so library scans are unaffected and uninstalling removes every trace.

Uncheck and Save to compare with stock Jellyfin. No restart required; this settings page stays available. Use this switch instead of Disable in Jellyfin’s plugin menu.

TMDb

Required. Free from your TMDb account under Settings → API.
An ISO code such as en-US, sv-SE or nl-NL.

What to show

How many external titles to add. Default 20.
How much TMDb popularity counts, 0–1. Default 0.6.
How much TMDb rating counts, 0–1. Default 0.4. Set popularity to 0 and this to 1 for a strictly highest-rated list.
Drops obscure entries whose rating is not meaningful. Default 100.
Only credits billed this high or better, e.g. 10 keeps the top ten billed cast. 0 disables the check.
TMDb often omits billing on television. A credit with no billing needs at least this many episodes to count as a real role rather than a guest spot. Default 5.
Turn off to include directing, writing and producing credits.
Avoids repeating what the native Known For row already shows.
Clients already grey these out, because they are marked the same way missing episodes are. Turn this on if a client of yours does not.

Requests and images

For example https://requests.example.com. When set, every external title carries a request link. Leave blank to disable.
A fallback for clients that do not render external links.
Redirecting stores nothing and uses no bandwidth. Switch to proxying only if a client will not follow the redirect.

Performance

A person is looked up once and then served from cache. Default 30.
How long a person page waits for a first-time lookup. If it runs over, the page renders normally and the lookup finishes in the background, so the next visit is instant. Default 4000.
